# Solar System Travel Guide: Eight Questionable Destinations

A fun presentation created by Jill Platts for NASA Solar System Ambassador community outreach.

Originally presented at the Oneida Public Library in Oneida, New York, this 45-minute program takes audiences on a tour from Earth to Neptune. Each destination includes its weather and environment, must-see attractions, major hazards, suggested packing list, and an overall vacation rating.

The presentation combines fun vacation-planning elements with real planetary science, NASA mission imagery, and information from NASA sources. Sources and image credits are included directly on the relevant slides.

## About the Solar System Ambassadors Program

NASA's Solar System Ambassadors program works with trained volunteers who share NASA science, missions, and discoveries with communities across the United States.

Learn more at [NASA Solar System Ambassadors](https://science.nasa.gov/engage/solar-system-ambassadors/).
