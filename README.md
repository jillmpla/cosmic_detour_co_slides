## 🧭 About the Program

The presentation explores all eight planets as if the audience were planning a vacation through the Solar System.

At each destination, travelers learn about:

- Weather and environmental conditions
- Must-see planetary attractions
- Major hazards
- Essential packing supplies
- Interesting planetary facts
- An overall vacation rating

The presentation combines fun vacation-planning elements with real planetary science, NASA mission imagery, and information from NASA sources. Sources and image credits appear directly on the relevant slides.

## 🔭 About the Solar System Ambassadors Program

NASA's Solar System Ambassadors program works with trained volunteers who share NASA science, missions, and discoveries with communities across the United States.

Learn more through the [NASA Solar System Ambassadors program](https://science.nasa.gov/engage/solar-system-ambassadors/).
